# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Construa um jogo da Forca em Python para praticar manipulação de strings, loops, condicionais e seleção aleatória. O jogador deverá adivinhar uma palavra oculta antes de esgotar as tentativas disponíveis.

## 📝 Tarefas

### 🛠️ Preparar a Palavra e Exibir o Progresso

#### Descrição
Crie a estrutura inicial do jogo: selecione aleatoriamente uma palavra de uma lista predefinida e mostre ao jogador uma representação da palavra com as letras ainda não adivinhadas ocultas.

#### Requisitos
O programa concluído deve:

- Selecionar aleatoriamente uma palavra de uma lista predefinida.
- Exibir o progresso da palavra no formato `_ _ _`, com uma posição para cada letra.
- Solicitar palpites de letras ao jogador.


### 🛠️ Controlar as Tentativas e Encerrar o Jogo

#### Descrição
Implemente o fluxo do jogo para atualizar o progresso a cada palpite e encerrar quando o jogador adivinhar a palavra ou esgotar as tentativas incorretas.

#### Requisitos
O programa concluído deve:

- Atualizar e exibir o progresso quando o jogador acertar uma letra.
- Rastrear e exibir o número de tentativas incorretas restantes.
- Encerrar o jogo quando a palavra for adivinhada ou as tentativas incorretas se esgotarem.
- Exibir uma mensagem indicando vitória ou derrota.
